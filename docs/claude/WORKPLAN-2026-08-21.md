### 0.2 notes — hedge mode on `bybit_1`
**What makes it safe, and it must be built this way:**
- `bybit_1` is `demo: True` → `api-demo.bybit.com`. `bybit_2` is mainnet. Different
  environments, so a mode switch **cannot** reach real money.
- Bybit's mode is settable **per-symbol** (ccxt `set_position_mode(hedged, symbol)`
  → v5 `/position/switch-mode`, `mode=3`). Scope it to the pairs' symbols only.
- **Build one resolver** — `bybit_position_idx(account, symbol, side)` — returning
  `None` (field omitted, today's behaviour) unless `(account, symbol)` is in a
  declared allowlist. **Empty allowlist = byte-for-byte no change**, which makes
  the diff provably inert for `bybit_2` and every non-opted symbol. Same shape as
  `NETTING_ATTRIBUTION_ACCOUNTS`.
- ⚠️ **The order path is `pybit`, not ccxt** — ccxt is only the market-data
  connector. The convenience method does not sit on the path that changes.
- **Surface to touch:** 9 order-write sites (`place_order` ×5, `set_trading_stop`
  ×2, `amend_order`, `cancel_order`) and 11 position reads (`get_positions` ×6,
  `get_open_orders` ×5). **Two are `src/runtime/orders.py` and
  `src/runtime/risk_counters.py` — Tier-3 hard-limit files.**
- **Semantic dependents that must be handled, not discovered:** the
  netting-attribution reconciler (running at `apply` on `bybit_1`) must
  **explicitly exclude** hedge-mode symbols — its premise is one position per
  symbol; `_bybit_position_protection` coverage arithmetic; the Bybit naked
  sweeps; `dashboard.py:257` aggregation.

**STEP 0, BEFORE ANY FLIP — an unresolved fact:** `bybit_portfolio` is *also*
`demo: True`. If it shares a demo UID with `bybit_1`, switching a symbol's mode
hits both books. Not answerable from config; needs an API read of account identity.

**Cheaper alternative, still open and worth 30 minutes first:** the constraint is
**symbol disjointness, not account isolation**. **BNB is not in `bybit_1`'s roster
at all.** A pair whose *both* legs sit outside the directional roster runs today
with zero code and zero credentials. None of the four researched pairs qualifies
(SOL/ETH/BTC are all heavily traded there: BTC 9 strategies, ETH 6, SOL 6), but if
cointegration work finds a viable non-roster pair, it is free.

**Done-condition:** hedge mode live on the pairs' symbols on `bybit_1` **and** a
subsequent `pairs_soak` window showing `open` events with **no** `half_open` rows.
