## Validation Performed
- **Tooling (offline, deterministic):** 15 new tests for the per-cell driver +
  backtest_system adapter (synthetic panels / injected fake harness); 9 new tests
  for the conviction_meta backtest source (mapper, panel reader, source_mode
  live/backtest/union, live-default byte-identity, bad-mode guard). The 39 existing
  research-panel tests + 10 backtest_system evidence tests + 11 existing
  conviction_meta family tests all pass. ruff clean (pinned 0.15.x). All three
  changed harnesses parse; live conviction_meta output is unchanged under the
  default `source_mode=live`.
- **Exit-timing study @ full-647k — LANDED (1525 trades).** Every *bounded* relay
  build timed out (500k/300k/250k/**150k**, exit 124), so the full feed was built
  via a **detached `nohup` build** (#7761) + read back (#7763): **1525 ict_scalp
  trades** (5.4× Study 7), 100% excursion coverage. **`win`: FDR survivor
  `cat_regime`, OOS AUC 0.538, all 5 folds > 0.5** — a thin but stable
  regime-conditioned ENTRY edge (concentrated in chop, 0.551). Exit outcomes
  `giveback_r`/`capture_ratio` **firmly NULL**; `mae_r`/`time_to_mfe` thin
  univariate FDR survivors, ~0 multivariate OOS. Read: "entries pure coin-flip" is
  too strong at scale; "edge lives in EXIT" is not supported from decision-time
  features. Full verdict in ledger Study 8.
- **Backtest infra fix (operator directive):** the relay time-wall is structural
  (the 647k feed is gitignored → lives only on the 1-OCPU contended trainer; the
  relay caps at 10 min). Diagnosis: the build is **CPU-bound** (per-bar
  `order_package` replay) — **GPU is the wrong tool**. Fix shipped: a self-contained
  **`research-panel-build` GH-Actions workflow** (#7764) that fetches the feed from
  Bybit's keyless public OHLCV + builds + runs C2 + per-regime on a 4-vCPU/6-h
  runner ($0, no trainer contention, no relay cap), reusing the `ict-scalp-backtest`
  pattern.
- **Relay-throughput wall (honest negative):** the ict_scalp harness runs at
  ~680 bars/s on the trainer, so a single 10-min `trainer-vm-diag` relay caps a
  build at ~150–200k bars; the 500k and 300k builds timed out (internal
  `timeout` exit 124). A full-647k or multi-hundred-k study requires **chunking
  across relays** (documented follow-up), not a single run.
