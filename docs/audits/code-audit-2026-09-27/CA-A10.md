## The lead: confirmed, root-caused, and generalized

The dispatcher's lead — `ict-git-sync.service` read `failed` on 2026-09-27, does the timer mask it (`PI-20260927-YZRZQ725-0002`) — is **confirmed mechanically and closed** (that pipeline record is now `done`; see the pipeline table below).

- **Root cause (MEASURED, live journalctl pull of the 06:31:51Z–06:38:06Z window):** a `git fetch` ref-lock race (`cannot lock ref 'refs/remotes/origin/main'`), which self-healed on the very next timer fire (~6 minutes later). A fresh live re-pull this session shows `ict-git-sync.service=inactive`, `ict-git-sync.timer=active` (healthy), including a successful pull of this very audit's own CA-A01 output — the VM is not stale.
- **Mechanism (MEASURED):** a failed timer-triggered oneshot's `Result` does **not** change its `.timer`'s `ActiveState`. The timer reads `active` regardless of whether the service it fires keeps succeeding or keeps failing. `ict-git-sync.timer` read `active` throughout the failure window — exactly what the dispatcher suspected.
- **Not git-sync-specific (CA-A10-401, MEASURED live, this session):** a second, independent, currently-failed instance of the identical class was caught in the same live pull — `ict-ib-executions-pull.service` failed on an IB Gateway connect refusal while its timer read `active`. Root cause there is a transient, fail-soft gateway blip (idempotent retry, circuit breaker, hourly retry) — not a code defect — but it is *invisible* to anything reading only timer state or `status-check`'s exit code.
- **Systemic cause (CA-A10-402, high, open):** zero of the 64 files under `deploy/` declare `OnFailure=`, and `scripts/ops/status_check.sh`'s exit code is gated on `systemctl is-active` for exactly 3 hardcoded long-running services — its broader `ict-*` enumeration is explicitly documented as read-only, head-capped at 60 lines, and never affecting the exit code. **No oneshot+timer pair in this repo (~20 of them) has any alerting path for its own failure.** Both live instances this session found were caught by an audit lane's incidental diag pull, not by any purpose-built check.
