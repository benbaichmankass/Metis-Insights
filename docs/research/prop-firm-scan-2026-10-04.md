## 0. The question and the lens

**Operator ask (2026-10-04 ~08:30Z, paraphrased by the manager):** a quick search for other prop firms that are *easy to work with*, judged against the experience we already have.

**Our experience, which is the selection lens** (from the docs above and the checklist rows `TRADEIFY-WIRE`, `PROP-TERM`):

- **DXtrade works headless from the VM.** `tradeify_1` is live; our browser-driven DXtrade executor fills tickets and reads them back. SOL submit is refused on that terminal for a reason still unknown (`TRADEIFY-PRICE-FILL`, 2026-10-04: not size). Breakout's *DXtrade* terminal also renders from datacenter egress; its DXtrade REST endpoint returned 403 RBAC, so on Breakout we drive the browser.
- **A bespoke web terminal behind Cloudflare does not.** Breakout's native terminal served an interactive Turnstile on the first response from 4 egress networks × 6 browser configs (measured 2026-10-04). Anything that is "our own terminal, no API" is in that class until shown otherwise.
- **We run Bybit and Alpaca natively.** A Bybit sub-account driven by our own key (the HyroTrader model) needs no new broker package.
- **Our strongest edges are crypto perps** (ETH/SOL trend, `ict_scalp`). A futures-only firm would need legs we have not validated for it.

So the ranking weights, in order: **(a)** platform we already drive (DXtrade, Bybit key, or a documented REST API) over a bespoke terminal; **(b)** bots/API *explicitly* allowed in the firm's own text; **(c)** datacenter-IP / VPS stance; **(d)** rule shape (static vs trailing drawdown, daily loss, min days, consistency, news/weekend); **(e)** payout reputation and firm age, with self-claims labelled; **(f)** fee for the smallest useful tier.

**Scope note.** The 2026-09-30 docs already covered ~25 firms (DXtrade white-labels, FX/CFD props, the futures majors). This scan re-checked the automation stance of the futures majors with fresh searches and added the firms that were *not* in those docs: **Velotrade, Propr, Crypto Fund Trader pricing, The Futures Desk, MyFundedPerps**. Firms the prior docs already ruled out are listed in § 3 with the prior citation; nothing there was re-derived.

## 2. Recommend next (at most two)

**1. Velotrade — one deep-dive lane, read-only until the operator says buy.** Three measurements, none of which needs an account:

- **Reachability from our egress.** `GET https://dx.velotrade.com/developers/` and the DXtrade login page, from the VM's egress class (the `egress-chromium-landing-probe` workflow already does this for Breakout; add the host). *Expected* 200 given the firm's VPS text, but Breakout's DXtrade terminal taught us to measure, not read.
- **The binding text.** The Terms / Trader Agreement bot, VPS and multi-account clauses verbatim (the pages read today are marketing and blog, not the agreement), plus the minimum-days and payout-eligibility rules the home page did not state.
- **Rule fit.** Write `config/prop_rulesets/velotrade_classic_1step.yaml` (7% static / 4% daily / 10% target / no consistency) and `velotrade_pro_1step.yaml` (3% / 3%), mark both `unconfirmed: true`, and run the P1 evaluator on the B3 book (`trend_donchian_eth_prop` + `trend_donchian_sol_prop` + `ict_scalp_xrp_15m`) the way `tradeify-portfolio-feasibility` did. A 7% static floor with no consistency rule is *looser* than Tradeify's 6%; the PRO 3% is tighter than anything we run.

If all three come back clean, the pilot decision is a $32–54 Tier-2 purchase. If the API is real, the executor is a thinner client than the browser adapter we maintain today.

**2. Propr — only on the operator's say-so,** and after Velotrade's result. It is the one firm whose own page invites agents, but it is the largest build in the table and the youngest firm with real money behind the split.

## 4. What this scan did **not** establish

- Nothing was measured from our own network. Every "VPS allowed" above is a sentence on a page.
- No Terms of Service or Trader Agreement was read end-to-end for any new firm; the quoted text is from FAQ, blog and help-centre pages.
- Reputation reads are two aggregators (Trustpilot counts as quoted by PropFirmMap, and PropFirmMap's own grade) whose methodology was not inspected. A Trustpilot profile that reads "suspended" on one page and "4/5, 8 reviews" on another is itself a flag.
- Velotrade's platform is reported as **DXtrade** by the firm (three pages, including the developer-portal URL) and as **"cTrader only"** by PropFirmMap. *Field beats comment*: the firm's own API docs decide, and the deep-dive's first fetch is exactly that URL.
- Propr's smallest-tier price is unresolved ($25 vs $125+).
- Budget: this lane spent well under its $15 ceiling; no paid service was used.
