# Retired training manifests

Manifests in this subdirectory are **excluded from the daily training cycle**.
`scripts/ops/run_training_cycle.sh` and `scripts/ops/train_and_register_ws5_baselines.sh`
enumerate manifests with `find ml/configs -maxdepth 1 …`, so anything under
`ml/configs/retired/` is no longer trained automatically. They are kept in-repo
(not deleted) so they remain runnable ad hoc:

```
python -m ml train ml/configs/retired/<manifest>.yaml --datasets-root ./datasets-out
```

## 2026-08-05 — W0.1 ML roster cleanup (M19 closed-negative families)

13 manifests retired in one pass: the **frozen-embedding** (7 + 1 corpusemb + 1 fcemb),
**TCN deep-sequence** (3), and **corpus-SSL** (1) families. Rationale per row above;
the shared disposition is `ROADMAP.md:29` — *"the `fc` forecast feature is the one
durable win … frozen embeddings / TCN deep-sequence / SSL wide-corpus encoder all
closed negative."* Daily-cycle manifests **89 → 76**.

**Safety precondition (verified, not assumed).** Retiring a manifest stops it being
retrained but does **not** unregister its model. A `shadow`-stage head auto-wires onto
strategy predictor lists, so de-training one would leave it **predicting while going
stale** — strictly worse than leaving it alone. Only `candidate`-stage heads (which the
shadow factory refuses outright) are safe to retire. Registry read 2026-08-05
(trainer-diag [#8500](https://github.com/benbaichmankass/Metis-Insights/issues/8500),
via `ModelRegistry` + `canonical_stage` over `ml/registry-store/*.json`): **95 entries —
candidate 63 · shadow 29 · advisory 3**. All 13 retired here are **candidate**; every
`shadow` and `advisory` head was excluded by construction.

**Scope is deliberately smaller than the 08-04 plan's "~35 → 25–30" target, and that is
the finding, not a shortfall.** Two families the plan named as drops have **open**
backlog items that retiring would have silently killed:
`setup-candidates-metalabel-xsym-yz-v1` is the subject of `MB-20260726-XSYMYZ-RANGEVOL-DEAD`
(open — proposes *rebuilding* its dataset), and the M23 metalabel family is still live
under `MB-20260717-M23-META-LABEL` (open — *"P2 next lever is label volume"*). Retiring a
manifest whose experiment is still open converts an open question into a silent no —
so those are **held**, not dropped. The remaining candidate-stage families (hmm ×5,
vt00 threshold arms ×4, baselines ×3) are plausible future drops but were left in place
here because no citable verdict was found for them this pass; a manifest retired without
a quotable verdict is the same anti-pattern as a guard that is cheaper to lie to than to
satisfy.
